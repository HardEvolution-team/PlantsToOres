# Plants to Ores Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Plants to Ores** by its original author.

- Original: https://www.9minecraft.net/?p=77615
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.25.0+

This port contains **no original assets**. Put your own copy of the original jar (`Plants_To_Ores_V1.0.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
